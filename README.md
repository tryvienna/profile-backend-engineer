# 🔧 Backend Engineer

> Debug production at the speed of thought

A Vienna content profile for backend engineers. Includes quick actions for error triage, database migrations, PR reviews, API development, log analysis, and incident postmortems.

## What's included

- **Quick Actions** — Triage Sentry errors, generate migrations, review PRs for security, write API endpoints, analyze logs, draft postmortems
- **Skills** — Getting started guide for Vienna profiles
- **Plugins** — Linear for issue tracking

## Install

Fork this profile in Vienna:

```
vienna://profile/github.com/tryvienna/profile-backend-engineer
```

Or go to **Settings → Profiles → Fork** and paste:
```
https://github.com/tryvienna/profile-backend-engineer.git
```

## Customize

After forking, this profile lives at `~/.vienna/profiles/backend-engineer/`. Edit any file to make it yours — add quick actions, swap plugins, tweak skills.

## Share

Push your customized profile to your own GitHub repo and share the `vienna://profile/...` link. Others can fork your version in one click.
